# PROGRESSION_MODEL

## 성장 축
- 월드/셀 진행: `battle` 및 `nextWorld` 중심.
- 업그레이드/장비/건물/직업: `newGame` 스키마와 `main.js` 구매/해금 로직 결합.
- 맵 진행: `runMap`으로 월드와 별도 보상 루프 제공.
- 리셋(포탈): `resetGame` + 포탈 관련 글로벌 상태 재시작.
- 후반 콘텐츠: `playerSpire` 서브시스템.

## 유지/초기화 관점(초안)
- 런 단위 전투/전개 상태는 리셋 시 초기화.
- 장기 메타 상태(포탈 횟수/최고 기록 등)는 `game.global`에 별도 누적 필드로 유지.
- 저장/로드는 `save`에서 휘발성/정의형 필드를 제거해 최소 상태를 영속화.

## 밸런싱 레버(1차)
- 자원 생산량(작업/자동화/버프)
- 전투 효율(공격/체력/블록/포메이션/모디파이어)
- 맵/월드 전환 보상 곡선
- 포탈/챌린지 보너스 누적 속도
- Spire 난이도/함정 비용 곡선

## 추가 분석 필요
- 유니버스(1/2) 및 챌린지별 분기 영향량 표준화.
- 리셋 후 유지 항목을 키 단위 매트릭스로 상세화.
